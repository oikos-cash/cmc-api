# Oikos CMC API

This simple API provides information about OKS circulating supply and total supply over a REST interface:

## Circulating supply
```
GET http://localhost:8088/api/circulating_supply 
```

Example response

```
519326.96494859917
```

## Total supply
```
GET http://localhost:8088/api/total_supply 
```

Example response

```
4306049.096086399
```
